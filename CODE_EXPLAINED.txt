  Line 89:     eps = 1e-15. This is the numerical floor we clip predictions to.

  Line 100:    Mean squared error between predicted probability and true label.

================================================================================
CROSS-FILE PATTERNS WORTH NOTING
================================================================================

1. LAZY IMPORTS EVERYWHERE
   Every integration file (mlflow, huggingface, wandb) imports its external
   library inside the method, not at the top. Same for report.py imports
   inside experiment.py (to avoid circular imports).
   Rule: import at the top level only if it's always needed and has no
   circular import risk.

2. DUCK TYPING FOR SOURCES
   decision.py uses hasattr(source, "promote") instead of isinstance checks.
   This means any object with a .promote() method works as a source —
   no base class required. Easy to extend without modifying evalbridge.

3. THREAD SAFETY IS EXPLICIT
   Every class that can be used concurrently has a threading.Lock:
   Experiment._lock, Bandit._lock, LiveRouter._lock, decorators._lock.
   The lock always wraps the minimum possible code — just the data mutation.
   Compute-heavy operations (Bayesian sampling, metric calculation) run
   outside the lock.

4. FIXED SEED IN BAYESIAN, NOT IN BANDIT
   BayesianABTest uses seed=42 for reproducibility — same data = same result.
   Bandit uses np.random.default_rng() with no seed — each route() call must
   produce independent random decisions for the exploration to work.

5. SNAPSHOT PATTERN IN evaluate()
   evaluate() acquires the lock, copies all data, releases the lock, then
   does all computation on the copies. This minimizes lock contention —
   log() calls from other threads are not blocked during the slow statistical
   computation (50,000 Beta samples).

6. JSON-SERIALIZABLE DATA ONLY IN _data
   log() converts everything to Python list of floats before storing.
   This guarantees that save() (which calls json.dump) will never fail due
   to non-serializable numpy arrays in _data.

7. GRADUAL IMPORT PATTERN IN experiment.py
   bridge.py, drift.py, and bandit.py are only imported inside the methods
   that need them (go_live, on_drift, as_bandit). This means loading
   experiment.py does not trigger loading those modules unless those features
   are actually used.
