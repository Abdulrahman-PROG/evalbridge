# Changelog

## 0.1.0

- Bayesian and sequential A/B testing for classification models
- Drift detection with PSI and KS test
- Multi-armed bandit with Thompson sampling and epsilon-greedy
- Offline → live bridge via go_live() and @evalbridge.track decorator
- Auto-decision hooks: on_drift() and on_confidence()
- MLflow, Weights & Biases, HuggingFace Hub integrations
- CLI: evalbridge report, evalbridge version
- HTML report generation (self-contained, no external dependencies)
- cohort-level A/B breakdowns
